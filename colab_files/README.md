# RoadLens on Colab: one standalone notebook

`RoadLens_standalone.ipynb` is the complete project in a single file. It needs no zip and no .py
file: all 86 source files (the `roadlens` package, the scripts, the configs, the tests) are inside it
as cells, and the notebook writes them to `/content/RoadLens` when it runs. The datasets (GTSRB,
BTSD) are downloaded from their official sites.

**How to run:** upload the notebook to Google Drive (or `File > Upload notebook` in Colab), choose
`Runtime > Change runtime type > T4 GPU`, then `Runtime > Run all`, and approve the Drive prompt.

**Settings** (first code cell): `PROFILE = 'pilot'` (1 seed, about 1-1.5 h, not measured), `'smoke'`
(minutes, only checks that things run) or `''` (full experiments, seeds 0, 1, 2; about 10-12 GPU
hours, not measured). `KEEP_ON_DRIVE = True` keeps checkpoints, results and the corrupted test sets
in `MyDrive/RoadLens_standalone/`, so if a session ends you just Run all again and finished work is
skipped.

**Outputs:** tables (CSV, TXT, LaTeX) and PDF figures in `MyDrive/RoadLens_standalone/results*/`;
the last cell also downloads them as a zip.

The notebook is generated by `scripts/make_colab_notebook.py` from the project files; after
changing the code, re-run that script rather than editing the notebook by hand.

## Testing the trained models: `RoadLens_test.ipynb`

Trains nothing. After (or during) the training notebook, open it in Colab with a T4 GPU, check
`PROFILE` and `SEED` in the first code cell (they must match the training run), and Run all. It
loads every finished `best.pt` from `MyDrive/RoadLens_standalone/runs*/`, tests it (clean accuracy,
the 14 corruptions x 5 severities with mCE, Belgian signs), shows a confusion matrix, example
predictions and predictions on your own uploaded photos, and saves the tables and figures to
`MyDrive/RoadLens_standalone/test_results*/`. It is generated by `scripts/make_test_notebook.py`.
